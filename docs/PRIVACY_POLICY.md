# API Flow Privacy Policy

**Effective date:** 21 August 2026  
**Publisher:** Jeffin Vinod K  
**Contact:** [jeffin@posteo.net](mailto:jeffin@posteo.net)

API Flow is a mobile API client. This policy describes how the published app handles data.

## Data stored on your device

API Flow stores request URLs, headers, query parameters, raw request bodies, saved collections, base URL preferences, and request-history metadata in Android app-private storage on your device. Android backups are disabled for the app. This data can contain credentials or other sensitive values if you choose to enter them, so do not save long-lived secrets unless your device is appropriately secured.

## Network requests

API Flow sends a request only after you select **Send request**. The request URL, headers, query parameters, and body are transmitted directly to the endpoint you choose. The publisher does not operate a relay, proxy, analytics service, advertising service, or account service for the app.

## Data collected by the publisher

The app does not collect, receive, sell, or share your saved workspace, requests, device identifiers, usage analytics, or advertising identifiers with the publisher.

## Your controls

You can delete individual collections and clear request history in the app. Clearing API Flow's storage through Android Settings removes all app-private data held by API Flow.

## Security

Use HTTPS endpoints whenever possible. Request data is stored in Android app-private storage, but the app is not a secret manager. Do not store long-lived production credentials in saved collections unless you have assessed the security of the device.

## Changes and contact

The publisher may update this policy when app data practices change. Questions can be sent to [jeffin@posteo.net](mailto:jeffin@posteo.net).
